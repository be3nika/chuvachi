# 🪨✂️📄 Чувачі

Камінь, ножиці, папір як Telegram Mini App. Гравці змагаються 1 на 1 у реальному часі, гра йде до 2 перемог.

## Що вміє
- ⚡ Пошук випадкового суперника
- 👊 Виклик друга посиланням (`t.me/твійбот?start=КОД`)
- ⏱ 15 секунд на хід: хто не встиг, отримує випадковий хід
- 🏆 Лідерборд
- 🔒 Ходи порівнює тільки сервер, а юзер перевіряється через `initData` від Telegram

## Стек
Node.js · Express · Socket.IO · grammY · чистий HTML/JS (Telegram WebApp SDK)

## Швидкий старт (локально, без Telegram)
```bash
npm install
npm run dev
```
Відкрий дві вкладки:
- http://localhost:3000/?dev=Вася
- http://localhost:3000/?dev=Петя

В обох натисни «Знайти суперника».

## Запуск у Telegram
1. У **@BotFather** напиши `/newbot` і скопіюй токен.
2. Отримай публічну HTTPS-адресу:
   - локально: `npx cloudflared tunnel --url http://localhost:3000` (або ngrok)
   - або задеплой на Railway / Render (див. нижче)
3. Створи `.env` на основі `.env.example`:
   ```
   BOT_TOKEN=...
   WEBAPP_URL=https://твоя-адреса
   DEV_MODE=0
   ```
4. `npm start` і напиши боту `/start`. Кнопка «Грати» з'явиться і в меню чату.

## Деплой (Railway / Render)
- Підключи репозиторій і вкажи команду старту `npm start`.
- Додай змінні `BOT_TOKEN`, `WEBAPP_URL` (адреса, яку видав сервіс).
- Потрібен **1 інстанс**: стан матчів зберігається в пам'яті.
